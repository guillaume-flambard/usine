# `openspec/` : historique de la v1

Rien ici n'est actif depuis le 14 novembre 2026 (Linear MEM-72). Les
changements de `changes/` sont des propositions de la v1 qui n'ont pas été
menées. Ils restent lisibles pour leurs idées, mais le backlog est dans Linear
(projet « Usine v2 : refonte agentique »), et les décisions sont dans
`docs/adr/`.

Spec Kit n'est pas utilisé, pour la même raison : une seule autorité par domaine
(ADR 0001).
